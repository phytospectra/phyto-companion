- **What was measured (2026-10-31, single run each, deterministic
  engine):**

     the user-created `.mzuser4` profile, `MZmineDetector.detect()` on
     MSV000090047's tetracycline mzML (SHA-256

  2. **Platform entry point:** the same dataset through

     `61a4bf375c5a9ac7`). Response preserved as
     `api_detect_response.json`.

     | feature | observed m/z | error (ppm) | RT (s) | RT (min) | height |
