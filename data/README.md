# data/

Curated marker data in this directory — `pharmacopoeial_markers.json` (the
pharmacopoeial QC marker table from ADR-0066, per DATA_SOURCES.md §9) — is
released under **CC0 1.0 (public domain dedication)**; the full text is in
[LICENSE](LICENSE). No attribution is legally required, but each entry carries
its own `reference` field citing the source pharmacopoeial monograph, and
citing the source is expected practice.

Third-party datasets referenced or inventoried here (e.g. NP-MRD, GNPS2,
COCONUT, METLIN) are **not** covered by this license — they are governed
per-source by [docs/DATA_SOURCES.md](../docs/DATA_SOURCES.md) and must not be
relicensed.
