# Phytospectra v0.1.0a1 — proposed research preview

Preparation only. No release, tag, deployment or DOI publication is authorized
by this file. Package versions remain `0.1.0`; `v0.1.0a1` is a proposed
prerelease label, not an already-published artifact. Final source revisions
and CI evidence are recorded in `COMPLETION-LEDGER-2026-11-09.md`.

## Verified scope

- Explicit real/mock scientific execution boundary with no silent fallback.
- One real orchestrated workflow: `reference_hsqc_identify`, using local
  formula-compatible structure retrieval and measured-reference HSQC matching
  supplied by the operator. Mandatory human checkpoint; no automatic identification.
- Transparent insufficient-evidence and ambiguity signals, evaluated before
  result truncation, with engineering defaults exposed in provenance.
- Cloud real science rejects offline mock authentication. Local contract
  collaborators remain usable; no public mock-token deployment is endorsed.
- Reference import/quarantine infrastructure. **No cleared measured library is
  bundled**: the attempted literature starter was quarantined after audit found
  missing per-record source/rights evidence and a quercetin identity inconsistency.
- Synthetic-only contract evaluation and a model-comparison harness. Neither
  is scientific accuracy validation; no model comparison inference was run.
- Existing MZmine/Thermo acceptance records and MS/MS assessments remain separate
  service evidence, not completion of general orchestrated workflows.
