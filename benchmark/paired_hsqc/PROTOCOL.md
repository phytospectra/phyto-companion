## Question and estimand

Given a known, independently established neutral molecular formula and independently acquired measured HSQC query, does A improve candidate-level supported ranking over B within the same frozen local formula-compatible structure/reference library, including ambiguity and truth absent from that library? This is bounded reference retrieval, not de novo elucidation, structure confirmation, mixture separation, or calibrated confidence. Primary endpoint: paired difference A−B in supported-correct preference on all present test queries (failures/abstentions count as not correct). Co-primary safety description: supported-wrong selections on all test queries, especially absent/ambiguous cases. A “supported” flag is an engineering signal, never scientific confidence.

## Eligibility, independence, and exclusions fixed before unblinding

Include known-formula single-compound measured queries with independently verified identity, rights for local use, stable source/acquisition IDs, assigned/provenance-reviewed peak lists, and acquisition metadata (solvent, temperature, pH where applicable, field, referencing, processing/peak-picking procedure). Query and reference must be separate acquisitions, not the same peak table re-exported, rounded, shifted, simulated, perturbed, or extracted twice from one spectrum. Public availability alone establishes neither rights nor independence. Different repository accessions do not by themselves establish separate acquisition. Curator review links acquisition IDs and raw-source hashes. Repeated acquisitions of one compound stay in one independence group, including stereochemical/near-identical structure families when leakage is plausible.

Exclude before outcomes: unresolved identity/formula, mixtures, unlicensed data, missing acquisition or assignment provenance, duplicate/reused query-reference acquisitions, predicted references, unsupported HSQC axes, and inputs beyond runtime limits. Keep a screened-case log with exclusion reason and reviewer, including unavailable cases; never remove a case because either arm fails. Acquisition-condition mismatch is prespecified as a stratum, not silently corrected/excluded post hoc. Incomplete/noisy spectra remain if independently measured and reviewable; artificial deletions/noise are secondary robustness regression only. No measured case may be derived from existing public pilot keys/packets. Raw spectra are not automatically processed by this harness; peak picking and any solvent/artifact exclusion must be frozen and reviewed before locking.

Private evaluator truth: `truth_status` present/absent/ambiguous; `acceptable_candidate_ids` is the adjudicated set (empty iff absent); `independence_group`; `partition` dev/test; `query_source_id`; `reference_source_ids`; `provenance_review` booleans rights_cleared, independently_acquired, identity_verified. Present truth must have exactly one accepted identity and that identity must exist among all structure IDs (not necessarily among formula-retrieved IDs, so formula/retrieval failures remain measurable). Ambiguous truth requires at least two defensible identities; uncertainty in *identity* is normally exclusion, whereas scientifically indistinguishable alternatives with verified underlying identity can be an ambiguity stratum after expert adjudication. Absent means verified identity absent from the whole frozen structure library, not simply absent from the hit list. Also report present-but-reference-missing separately. Schema assertions and disjoint source IDs are necessary but not proof; signed source/rights/independence review is mandatory outside the repository.

## Retrieval and split lock

Use FileStructureDB exact elemental-count formula retrieval, neutral formula only, no mass-window retrieval, online augmentation, candidate insertion using hidden truth, or manually selected easy decoys. Both arms see the **same complete** sorted candidate set and measured references from the same files. Include formula isomers/close alternatives when actually in that frozen library. Record missing-reference candidates, zero-candidate queries, candidate counts and all reference counts. Multiple references per candidate are all searched; best reference defines candidate score in both arms, with a prespecified sensitivity analysis limiting to one condition-compatible reference chosen without query outcome. Reference multiplicity is a library bias, not independent sample size.

Dev and test are split by compound/family/acquisition independence group; no group crosses splits. Freeze library, all queries (including dev, so split overlap can be detected), external key digest, screening log/adjudication artifact, code/protocol digests, package versions, hardware and candidate retrieval set in a retained lock. Dev may inform a future protocol revision, never this locked test run; any change gets a new version and fresh untouched test set. Do not expose evaluator keys to arm execution, LLMs, public artifacts or source control. All measured bundle and report paths must be outside the repository; local external storage still needs appropriate access controls. Hashes detect subsequent drift, not honest preregistration or source authenticity.

## A and meaningful simpler B

**A:** direct invocation of the real `RealToolExecutor.execute("reference_hsqc.rank", inputs)` used by `reference_hsqc_identify`, with the production registry, `FileStructureDB`, existing `match_hsqc` and evidence assessment. This harness benchmarks the production ranking executor, **not** PlannerAgent/WorkflowEngine orchestration or its human-review/audit-write path; every preference still requires human review. Rectangular Hungarian one-to-one assignment minimizes capped pair costs. Pair cost is `4 * min(sqrt((ΔH/.05)^2+(ΔC/.5)^2)/sqrt(2),1)` when both absolute differences are within tolerances, otherwise 4. Sum selected costs divided by max(query count, reference count); lower is better. Excess unassigned peaks have **no explicit penalty**, and division can reward unequal counts: retain this limitation, do not silently fix A during evaluation. Assignment cost strictly <4 defines a matched peak, so a pair exactly on both tolerance boundaries costs 4 and is not counted matched. No intensity/multiplicity/solvent correction.

**B:** directed query-to-nearest-reference distance/coverage, a credible spectral lookup baseline without a global one-to-one constraint. For every query peak take the minimum **same** capped pair cost across the reference; average across all query peaks, including unmatched cost 4. Count cost<4 query peaks for coverage and distinct matched coordinates. Many queries may select the same reference peak. Same best-reference candidate aggregation and assessment precedence as A. This is not random/index pairing or an intentionally weakened baseline: B uses all references, formula retrieval, tolerances, unmatched query penalties and ambiguity/abstention controls. It can handle redundant query peaks better but may overcount one reference and does not penalize extra reference peaks. Difference is not a pure isolated Hungarian ablation because normalization/excess-peak handling differ; report count-stratified results and do not attribute all differences solely to assignment.

Both: H tolerance .05 ppm; C .50 ppm; cap 4; ≥3 distinct matched query coordinates; query coverage ≥.50; any retrieved candidate without reference forces insufficient evidence; best-versus-next **different candidate** gap <.25 distance units is ambiguous. No hits → no_hits; otherwise insufficient → ambiguous → ranked. Equality at .25 is separated. Float round gap to six decimals as runtime does. Candidate/reference ID lexical order is display-only tie resolution; a near tie cannot become a supported win. `max_results=100`; bundles with >100 matching references per formula are rejected before evaluation to avoid silent truncation. Candidate top-k lists are unique candidates, not repeated spectra. No post hoc tolerance optimization. Uncalibrated 'ranked' is reported as supported preference, not confidence.

## Outcomes, failures, uncertainty, runtime

Scorer reports numerator, denominator, value and descriptive Wilson 95% intervals for binary rates: retrieval recall among present queries, reference retrieval recall, raw top-1 and top-3 (top-3 means min(3,candidate count)), supported-correct preference among present, supported coverage on all queries, supported wrong on all queries, wrong among supported selections, abstention among absent, and ambiguity flag among ambiguous queries. Raw lexical tie ranking is diagnostic only. Absent abstention = no_hits/insufficient/ambiguous, **not proof of true absence**; selecting anything with ranked disposition on absent truth is a supported error. Ambiguous ground truth must not be scored uniquely correct merely because its lexical first ID appears in the acceptable set: unique preference is unsupported; report ambiguity and abstention separately. Report unavailable-reference stratum, identity families, acquisition mismatch, candidate/reference/query counts, exact per-case outputs and runtime.

Every locked test query contributes one planned slot per arm. Missing, duplicate, malformed, exception and timeout slots are failures; never silently retry/cherry-pick. Preflight configuration errors abort rather than fabricate observations. Run-level A/B exceptions become failure slots; failed slots count zero in primary endpoint and remain visible separately. Scoring aborts on foreign case/arm IDs or lock mismatch; foreign hit IDs and invalid per-slot output shapes become malformed failure slots, and duplicate case/arm slots become duplicate failure slots. No duplicate can replace a failure with a success. This preserves the denominator without accepting a foreign prediction. Report paired endpoint difference on full planned present denominator, discordant counts and matched-success sensitivity denominator. Wilson intervals assume independent queries and are only descriptive when groups repeat. Final inference: paired cluster bootstrap by independence group (10,000 resamples, seed 20261109) for A−B CI, with all group members retained; exact McNemar only if one independent query per group. The executable scorer supplies deterministic cluster-bootstrap endpoint CI and marks repeated-query Wilson limits. No inference from synthetic results.

Target proposal: 100 independent present groups plus 50 absent groups and ≥20 ambiguity challenges (may overlap a prespecified present stratum; distinct truth_status in executable dataset). At p=.5, n=100 gives roughly ±10 percentage points, n=50 roughly ±14 points; zero errors in 50 absent cases still permits about 6% upper one-sided 95% error (rule of three). A paired 10-point gain with 30% discordance needs about 235 independent present pairs for 80% normal-approximation power at two-sided .05; therefore 100 is feasibility/precision, **not a powered superiority claim**. Lock attainable counts before outcomes; smaller sets are pilot/descriptive. Repeats/reference spectra do not inflate n. Do not claim acceptance merely from passing synthetic contracts.

Runtime measured using monotonic wall clock per arm per query including arm-specific retrieval/matching and compact output conversion; shared library loading/preflight separately, not amortized away. A does not include workflow planning, audit writes or human review. B uses the same loaded executor's validated database/reference records, but never invokes A's matcher. Outputs record every reference score, matched query/distinct counts, reference size, unique candidate rank, missing-reference IDs and query size; source/acquisition evidence remains in external evaluator artifacts. No HTTP/auth/LLM latency is represented. Fixed single sequential process, same machine/package versions, interleaved A/B order reversed on alternate cases, no warm-up omitted from denominator. External supervisor wall cap proposal: 60 s per arm/query and 30 min run; current harness records elapsed time and marks >60 s as timeout **after completion**, not hard cancellation. Supervisor must enforce hard caps before final measured run; non-returning processes otherwise block. No inference/service/network calls; zero provider charge is not zero compute cost.

## Execution and private artifacts

Exact runnable commands and schemas are in README.md. `evaluate.py synthetic --bundle EXTERNAL_NEW_DIR --keys EXTERNAL_NEW_FILE` generates invented numeric fixtures only; it does not run inference or scoring. `lock --bundle EXTERNAL --keys EXTERNAL --output EXTERNAL` validates evidence and writes a review-pending prospective snapshot; `run --bundle EXTERNAL --lock EXTERNAL --output EXTERNAL` never loads keys or imports the scorer; `score --bundle EXTERNAL --lock EXTERNAL --keys EXTERNAL --records EXTERNAL --output EXTERNAL` is evaluator-only. Existing outputs are never overwritten. Bundle files: structures.csv and references.json in existing runtime format; queries.json strict list of {case_id,formula,peaks:[{h_ppm,c_ppm}],partition}; manifest.json {classification,review_artifact_sha256}, classification `independent_measured` or `synthetic_contract`. The digest is of the external key's canonical `evidence` object, not a substitute for independent review. All query partitions must be supplied even though scoring includes only test slots. No template claims an expert review has occurred.

Keys are always external to this checkout, including synthetic keys. All measured bundle/lock/prediction/report paths must resolve outside it. A snapshot serializes only the private key byte digest, never key path/content; prediction artifacts contain only input hashes and inference outputs. Private score reports intentionally include adjudicated truth status and group IDs and must not be published without disclosure review. The inference interface has no keys/truth parameter, accepts only allowlisted queries and does not read private evidence. This is a code/data-flow boundary, not an OS sandbox: evaluators must use separate access-controlled directories/process identities to enforce adversarial isolation. Candidate names/source fields still need semantic leakage audit before scientific use. The caller must not place answer-bearing text in any public library or query field.

Snapshot binds all bundle byte hashes, complete per-case retrieval reference IDs, fixed configuration, HEAD revision plus actual Python source hashes (including dirty changes in shared/elucidation/orchestrator), protocol hash, provider/dependency versions, Python and machine metadata. Running or scoring after drift aborts; running checks again before writing. No hard-cancellation guarantee is claimed. Runtime values are intentionally not deterministic; a separate semantic prediction hash excludes elapsed seconds. Missing-slot scoring permits a supervisor to submit a partial run with intact header/config/lock ID after hard termination; absent planned records become missing failures. No silent retry is provided.

Scientific validation fails closed unless external evidence covers every query and loaded reference source ID, verifies rights/independent acquisition/external adjudication, supplies acquisition/raw hashes and acquisition metadata, has no reused query/reference acquisition or raw hash, has no duplicate query acquisition, clears every case provenance flag, and separates groups, accepted compounds and source acquisitions across dev/test. Reference `source` must be the evidence source ID. Source/raw identity may not cross partitions, including references; hence the scientific library must have disjoint source use across partitions. Absent identity and family grouping require external adjudication because the executable accepted-ID set cannot prove absence or discover chemically related families. Hashes/booleans are curator attestations, never proof of authenticity. Empty or merely relabelled synthetic evidence is rejected.

The scorer reports full planned-slot denominators, not only complete pairs. Exceptions/timeouts/missing/malformed/duplicates are failures, never chemical abstentions. Raw top-k is unique-candidate diagnostic retrieval ranking (k=3, fewer candidates use all available ranks); ambiguous cases have no uniquely correct endpoint and a ranked preference counts as a supported safety error even if in the accepted set. Query-level Wilson intervals are descriptive; the primary paired present endpoint uses a query-weighted ratio cluster bootstrap, sorted groups, seeded Python PRNG, 10,000 draws of whole compound groups with replacement, nearest-rank 2.5/97.5 percentiles. Empty samples yield null rates/CI; one cluster is marked degenerate. Exact two-sided McNemar is emitted only for at most one present query per group (no discordance gives p=1). Matched-success sensitivity excludes neither arm's successful abstentions, but excludes any pair with a technical failure. Per-case rows permit prespecified reference-missing/count/condition strata; no post hoc stratum is a new primary endpoint.

Blockers today: independent measured acquisitions and separately measured reference records; record-level local-use/redistribution/inference permissions; verified structural/assignment ground truth; acquisition compatibility and independence review; enough close alternatives and absent/ambiguous controls; held-out group split/screening log; expert adjudication and frozen external timestamped lock; hard timeout supervisor and immutable secondary model pin. No scientific outcomes or expert endorsements have been generated.
