# DNS records in the Cloudflare dashboard for BOTH Phytospectra zones
# (phytospectra.com and phytospectra.org; both registered 2026-10-21 at
# Cloudflare). Every hostname serves the Cloud Run web app — there is no
# download site and no .org redirect anymore (ADR-0077).
#
# Dashboard path: Cloudflare dashboard -> <zone> -> DNS -> Records -> Add record
#
# Per zone, the same three-record shape applies:
#
# 1. Root — Google issued A records for the apex (a CNAME cannot coexist
#    with other apex records, and Cloudflare flattening is not needed):
#    Type: A      Name: @   216.239.32.21   Proxy: DNS only (grey cloud)
#    Type: A      Name: @   216.239.34.21   Proxy: DNS only
#    Type: A      Name: @   216.239.36.21   Proxy: DNS only
#    Type: A      Name: @   216.239.38.21   Proxy: DNS only
#    Optional IPv6 (AAAA, same name @):
#      2001:4860:4802:32::15  2001:4860:4802:34::15
#      2001:4860:4802:36::15  2001:4860:4802:38::15
#
# 2. www
#    Type: CNAME   Name: www   Target: ghs.googlehosted.com.   Proxy: DNS only
#
# 3. app
#    Type: CNAME   Name: app   Target: ghs.googlehosted.com.   Proxy: DNS only
#
# These can also be applied by script, both zones in one pass:
#   export CLOUDFLARE_API_TOKEN=...          # Zone.DNS Edit on both zones
#   DRY_RUN=1 infrastructure/cloudflare_dns_setup.sh   # preview
#   infrastructure/cloudflare_dns_setup.sh             # apply
# The script deletes stale address records at those names (old download-site
# CNAMEs, .org redirect placeholders) and leaves MX/TXT records untouched.
#
# IMPORTANT — Cloud Run domain mappings must exist for SSL to be issued:
#   gcloud beta run domain-mappings list --project phyto-companion-prod --region us-central1
# .com mappings: all three created (app.phytospectra.com LIVE).
# .org mappings: NOT yet created — gcloud domains verify phytospectra.org
# opens Search Console; complete verification in the browser, then create the
# three .org mappings (commands in docs/DEPLOYMENT_GCP.md).
#
# SSL certs provision automatically once DNS points at Google and the mapping
# exists; allow ~15-60 min, then check `gcloud beta run domain-mappings describe`.
#
# Smoke-test once certs are provisioned:
#   for h in phytospectra.com www.phytospectra.com app.phytospectra.com \
#            phytospectra.org www.phytospectra.org app.phytospectra.org; do
#     curl -sI "https://$h/" | head -1 | sed "s|^|$h: |"
#   done
#   (expect HTTP/2 200 on all six)
#
# --- Cleanup of the retired download site ------------------------------------
# Buckets gs://phytospectra.com, gs://www.phytospectra.com and
# gs://phytospectra-downloads held the desktop installers and can be deleted
# once DNS no longer points at them.
#
# --- Email (optional, skippable) ----------------------------------------------
# MX/SPF/DMARC records only if mailboxes are set up for the domain.
